MOVIEBOOK - BOOKMYSHOW STYLE JAVASCRIPT PROJECT

Files:
- index.html
- style.css
- script.js

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome/Edge/Firefox.
3. Select a movie.
4. Select a show time.
5. Select seats.
6. Click Confirm Booking.
7. Click Close Window.

Note:
Modern browsers generally prevent JavaScript from closing a normal tab that the user opened manually. window.close() works when the page/window was opened by JavaScript (window.open()). The project includes a fallback message for normal tabs.

This is a frontend demo and does not process real payments or store real bookings.
